## 判定: ❌ 未达落地线 (需 ≥60% 单票占优)

53% 占优 < 60% 及格线，按 135 项目既定方法论**不能冻结落地**。
但方向正向 (组合收益 30.6% > 17.9%，回撤相当，收益/回撤比 2.47 > 1.42)。

## 关键观察

1. **组合收益强但单票占优不足** — 组合层 (10%×5只) 把威科夫的正向收益放大，但按单票中位数/占优率看，约 1/4 股票威科夫比 V18-ATR 差。符合 135 项目教训: 信号层单票层面信息有限，结构层(组合/止损)才是有效 alpha。
2. **胜率 22.1% vs 交易数 77** — 威科夫交易频率高于 135 (77 vs 21)，单笔胜率偏低但靠吊灯止损让利润飞，组合净值仍跑赢。
3. **R1 顶部离场** 默认开启，把派发 Upthrust 作为风控离场信号 (仅 A 股做多场景，用于离场不做空)。

**结论: 浅破收紧 (下穿深度≤3%, 排除深破Spring#1型) 未提升占优率 (56%→55.6%), 基本无增益。**
→ 说明全池 Spring 信号绝大多数已是浅破, 深度约束无区分度。Spring(S1) 是核心 edge, 但独立落地仍卡 60% 线下方。
脚本: `run_wyckoff_s1_shallow.py` (get_hs300_codes(300), 全池266只)。

## 步骤② 并入 135 组合层 (完成 — 负向)

把 威科夫 S1(Spring) 与 135 V18 作为两个候选信号源, 全池266只回测:

| 口径 | V18-only | V18+威科夫S1 融合 |
|---|---|---|
| 单票占优率 (融合>V18) | — | **118/266 = 44.4%** (落地线≥60%) |
| 单票中位收益 | -7.2% | -6.7% |
| 组合层总收益 | +17.88% | **-5.47%** |
| 组合层最大回撤 | 12.59% | 9.84% |
| 收益/回撤比 | 1.42 | -0.56 |
| 交易数 | 21 | 85 |

**结论: ❌ 融合方向不成立。**
1. 单票占优率 44% << 60% 落地线, 威科夫 S1 加入对多数股票是减分的。
2. 组合层转负 (-5.47% vs +17.88%): 威科夫 S1 信号密度高(77 vs 21笔), 在"先到先得"名额竞争里抢占了本该给 V18 的信号名额 → 拖垮。
3. ⚠️ 当前为拼接法, 同股两源重叠时段存在双计 (数字偏低); 但单票占优 44% 的方向性结论稳健 — 威科夫加入对多数股票减分。
4. 再次验证 135 核心教训: **alpha 在结构层(组合资金管理+止损), 而非单一信号层。** "独立组合层正收益(+29~30%)" ≠ "与 V18 融合正收益"。

## 任务14 总结判定

威科夫 Spring(S1) 是核心 edge (S1-only 占优56% > 全信号53%), 但:
- 独立落地: 单票占优卡在 53~56% (<60% 线), 不过方法论落地线; 独立组合层 +29~30%、收益回撤比2.47 是正向的"卫星策略"候选。
- 浅破收紧: 无增益 (55.6%), 全池 Spring 多数本就浅破。
- 并入135融合: 负向 (占优44%、组合层-5.5%), 名额竞争效应拖垮。
→ **建议不并入 135 主配置**; 若要用, 仅作"纯威科夫 Spring 组合层"独立卫星策略, 与 135 V18 分账户并行, 不混合。
