# 威科夫交易法 研究笔记（量化策略素材）

> 收集日期：2026-09-24 ｜ 目的：为威科夫量化策略做知识储备与信号定义
> 主线来源：Wyckoff Analytics 官方、FTMO、TradingSim、ZeaFx、LuxAlgo、民生证券量化专题（概率云表达）

## 一、三大基本定律（量化的出发点）

| 定律 | 内容 | 量化表达 |
|---|---|---|
| 供需定律 | 需求>供应→涨；供应>需求→跌；均衡→横盘 | 量价对比：放量滞涨=供应；缩量下跌=供应衰竭 |
| 因果定律 | 交易区间(TR)的"因"孕育趋势的"果"：横有多长，竖有多高 | 用 P&F 点数或时间×波动幅度量化区间强度，预估后续行情空间 |
| 努力与结果 | 成交量是努力，价格变动是结果；努力与结果背离预示转折 | 量价背离指标：放量但价格几乎不动 = 吸筹/派发特征 |

## 二、市场周期四阶段

```
Markup(上升) → Distribution(派发,顶部TR) → Markdown(下跌) → Accumulation(吸筹,底部TR)
```
机构无法一次性建仓/出货，故在区间内用数周至数月缓慢完成——这是威科夫逻辑的核心假设。

## 三、吸筹（Accumulation）图式

**事件（Events）：**
- **PS** Preliminary Support 初步支撑：下跌中出现首次放量止跌（主力试探性承接）
- **SC** Selling Climax 卖出高潮：放量急跌，区间最低点（TR下界）
- **AR** Automatic Reaction 自然反弹：高潮后的技术性反弹（TR上界候选）
- **ST** Secondary Test 二次测试：缩量回踩SC低位附近，缩量=供应枯竭
- **Spring / Shakeout**（阶段C）：跌破TR支撑后**迅速收回并收盘回到区间内**——空头陷阱，主力洗盘。末端剧烈版称 Terminal Shakeout（TSC）
- **Test**：Spring 后的缩量再探底（常形成更小的下影/更高的低点）
- **SOS** Sign of Strength 强势信号：放量、幅度变宽的上攻
- **LPS** Last Point of Support 最后支撑：SOS 后缩量回调的支撑点
- **BU / BU-to-creek** Back Up：突破后回踩（"跳河后回到河边"），回踩原阻力
- **阶段E**：放量突破TR上界，上升趋势确立

**区间边界**：TR 下界 = SC 低点（及其 ST/Spring），上界 = AR 高点（及其 UT 型动作）。

**Spring 按成交量分三型**（ZeaFx）：
| 型 | 特征 | 可靠性 |
|---|---|---|
| 1（放量深破） | 深度下穿+巨量，需立即强需求收回 | 最危险，需最强确认 |
| 2（中等量） | 有限下穿+放量不明显 | 最常见，需后续 Test 确认 |
| 3（缩量浅破） | 几乎不跌破、量枯竭 | **最强，缩量本身即确认**，可直接交易 |

**吸筹不一定有 Spring**（Schematic #2：区间内更高点位的缩量测试同样可判定阶段C）。

## 四、派发（Distribution）图式（吸筹的镜像）

- **PSY** Preliminary Supply 初步供应：上涨末段首次放量滞涨
- **BC** Buying Climax 买入高潮：放量冲高（TR上界）
- **AR**：回落
- **ST / UT** Upthrust 上冲回落：突破TR上界后迅速收回区间内——多头陷阱（UTAD = 派发后上冲，Spring 的镜像）
- **SOW** Sign of Weakness 弱势信号：放量下探至TR下界
- **LPSY** Last Point of Supply：缩量弱反弹
- **阶段E**：跌破TR下界，下降趋势确立

⚠️ A股只能做多 → 派发识别用于**规避/离场**（识别顶），不用于做空。

## 五、量化工化要点（从主观到量化）

1. **TR 检测**：近 N 日高低点构成箱体；要求 SC/BC 有显著放量（如 vol > 2×20日均量）、区间持续 ≥ 若干周（因果定律：区间越长后续预期越强）
2. **Spring 检测**（核心买入事件）：
   - `low < TR_low` 且 `close > TR_low`（收回区间内）
   - 下穿当日量 **< 区间内均量**（缩量洗盘特征，区别于真跌破）
   - 收回确认日最好放量（SOS雏形）
   - Spring 低点 = 止损位（右侧交易：收盘收回后入场，止损放Spring低点下方）
3. **Test 检测**：Spring 后 1~2 周内再探底部、量更小、低点抬高或平 → 加仓/确认点
4. **SOS/突破检测**：放量（>均量×1.5~2）收上 TR 上界 → 第二入场点
5. **因果量化**：区间天数或 P&F 计数 作为目标位预估（目标 = 区间幅度 × 系数，或直接用 P&F 列数）
6. **Weis Wave（Weis 波浪量）**：把量按交替波段归集（上波段量 vs 下波段量），比较"努力"的净方向：下探时量递减=供应枯竭（吸筹信号）；上攻时量递减=需求枯竭（派发信号）
7. **Effort vs Result 背离**：`|Δprice|/ATR` 相对 `vol/MA(vol)` 的比值在区间端点异常 → 转折预警

## 六、与用户交易哲学的映射（Jesse）

| 用户原则 | 威科夫对应 |
|---|---|
| 只做多 | 只做吸筹图式（Spring/Test/SOS），派发图式仅用于风控离场 |
| 右侧交易 | 入场 = Spring 收回区间内（收盘确认）或 SOS 突破，不做左侧抄底 |
| 生存优先 | 止损 = Spring/SC 低点下方（结构性止损位，非百分比） |

| 验证标准 | 全池≥60%占优才落地（沿用135方法论） |
