## 二、抄底篇 — 底部反转策略

### 2.1 红杏出墙（#1 — 核心买点）

```
【形态定义】
均线系统呈典型空头排列，股价长期下跌远离55日均线。
13日均线由下降趋于走平，股价从下向上突破13日均线，
并且在13日均线上企稳。这根站在13日均线上的阳线称为"红杏出墙"。

【量化条件】
1. ma13[t] > ma13[t-1]  AND  ma13[t-1] <= ma13[t-2]  # 13日均线走平转升
2. close[t] > ma13[t]  AND  open[t] < ma13[t]  # 阳线站上13日线
3. ma55[t] > ma55[t-1]  AND  ma55[t-1] > ma55[t-2]  # 55日线仍下行（空头排列）
4. (ma13[t] - ma55[t]) / ma55[t] < 0.15  # 距离未过大
5. volume[t] >= MA(volume, 5) * 1.2  # 放量确认

【操作要点】
- 首次红杏出墙：轻仓试探（1-2成仓位）
- 配合指数环境配合：半仓跟进
- 止损：跌破13日均线
- 目标：34日均线上穿55日均线时加仓
```

### 2.2 金屋藏娇（#3 — 底部见底）

```
【形态定义】
股价经过长期下跌，反而选择向下突破，呈带量加速之势，
但最后一根阴线留下长长的下影线，表明底部承接有力。
第二天低开低走但不创新低，成交量萎缩，表明抛盘穷尽。
躲在昨日阴线下影线里面的小阴线称为"金屋藏娇"。

【量化条件】
1. 存在一根放量长阴线：close < open AND (open - close) > body_avg * 2
2. 该阴线下影线长度 > 实体的1.5倍：(min(open,close) - low) / (open - close) > 1.5
3. 次日：close < open AND close > low_of_prev  # 小阴线在长阴下影内
4. volume[t] < volume[t-1] * 0.7  # 缩量
5. low[t] > low[t-1]  # 不创新低

【操作要点】
- 典型见底形态，可重仓介入
- 止损：跌破金屋藏娇最低点
```

### 2.3 日月合璧（#4 — 底部反转）

```
【形态定义】
股价从高点回落，成交量极度萎缩，13日均线跌势趋缓。
在下跌尾段股价跳空低走收平底或略带下影阴线，
但第二天止跌回升收阳线。两根并排阴阳K线称为"日月合璧"。

【量化条件】
1. volume[t-2] 连续3日递减至地量水平
2. day[t-1]: open > close (阴线) AND gap_down (跳空低开)
3. day[t]: open <= close (阳线) AND close[t] > open[t-1] (覆盖昨日)
4. ma13[t] 斜率趋平：ma13[t] - ma13[t-3] ≈ 0

【操作要点】
- 轻仓摸索，次日阳线确认后半仓跟进
- 站稳55日线时重仓出击
```

### 2.4 四渡赤水（#5 — 底部筑底）

```
【形态定义】
股价长期下跌后强劲反弹，但在跌幅2/3处回落，
经过若干时间整理再次冲击前期反弹高点，再次受阻回落，
如此反复四次后，庄家收集、洗盘、拉升前准备完毕。

【量化条件】
1. 存在4次反弹-回落的波段结构
2. 每次回落低点抬高：low[wave1] < low[wave2] < ... < low[wave4]
3. 每次反弹高点也抬高：high[wave1] < high[wave2] < high[wave3] < high[wave4]
4. 成交量逐次放大后缩量

【操作要点】
- 第4次回落后开始介入
- 止损：跌破第4次低点
```

### 2.5 八仙过海（#7 — 底部转势）

```
【形态定义】
股价长期横盘整理后，伴随温和成交量，持续拉出8根小阳线
（含星形阳线），表明庄家限价买入进入尾声，预示转势。

【量化条件】
1. 连续8根K线：阳线或星线（实体 < 2%）
2. 每根涨幅 0.5%-3%
3. volume 温和放大（非爆量）
4. 8根累计涨幅 5%-15%
5. 均线系统开始胶合

【操作要点】
- 第8根确认后介入
- 止损：跌破8根K线最低价
```

## 三、转势篇 — 趋势反转策略

### 3.1 黑客点击（#10 — 核心买点）

```
【形态定义】
股价从前期明显高点回落，在底部区域充分整理后，
有效突破55日均线后开始回落，在55日均线附近获得支撑。
如果K线收阴，回落股价恰好落在13日均线与55日均线的结点处。

【量化条件】
1. 存在前期高点（可设为N日最高价）
2. 股价曾突破55日均线
3. 突破后回落：low[t] 接近 ma55[t]（误差 < 2%）
4. 13日均线与55日均线交叉点：abs(ma13[t] - ma55[t]) / ma55[t] < 0.02
5. close[t] 接近结点处

【操作要点】
- 均线互换完成后可重仓
- 放量上攻时毫不犹豫进场
- 涨幅达20%后若13日线走软先出局
```

### 3.2 红衣侠女（#11 — 均线金叉）

```
【形态定义】
股价经过长期下跌或充分调整，55日均线基本水平，
股价沿13日均线爬至55日均线附近窄幅整理。
在13日均线上穿55日均线之日，携量上攻，形态成立。

【量化条件】
1. ma55[t-2] ≈ ma55[t-1] ≈ ma55[t]（水平）
2. ma13[t-1] < ma55[t-1]  AND  ma13[t] > ma55[t]  # 金叉
3. close[t] > open[t]  AND  close[t] > ma55[t]
4. volume[t] >= MA(volume, 5) * 1.5

【操作要点】
- 立即上涨或调整后再放量起涨
- 是即将拉升的标志
```

### 3.3 海底捞月（#12 — 均线回穿）

```
【形态定义】
13日均线相继向下突破中、长期均线后，下跌均势减缓。
随着成交量放大，股价缓步盘升，13日均线重新向上穿越55日均线。
13日均线下穿再上穿55日均线的过程。

【量化条件】
1. ma13[t-k] > ma55[t-k]  # 此前13在55之上
2. ma13[t-1] < ma55[t-1]  # 下穿
3. ma13[t] > ma55[t]  # 上穿回
4. volume[t] 温和放大

【操作要点】
- 中长期均线平行移动说明市场认同当前价位
- 13日重新上穿表明新资金进场
- 短期仍持续走高
```

### 3.4 均线互换（#13 — 趋势确认）

```
【形态定义】
34日均线顺势下穿55日均线，后在成交量推动下止跌企稳重返55日均线，
34日均线顺势上穿55日均线。均线互换的完成标志着股价开始走强。

【量化条件】
1. ma34[t-1] < ma55[t-1]  AND  ma34[t] > ma55[t]  # 34上穿55
2. 此前有 ma34 > ma55 的历史（下穿后再上穿）
3. volume[t] 放大

【操作要点】
- 此后均线系统构成多头排列
- 后市必有一波上攻行情
- 中线持有
```

### 3.5 一阳穿三线（#15 — 底部突破）

```
【形态定义】
股价经过长期下跌和充分整理，均线系统下跌斜率趋缓并向一起靠拢，
波幅日益收窄。某一天突然放量穿越所有均线（13/34/55）。

【量化条件】
1. abs(ma13[t] - ma34[t]) / ma34[t] < 0.05  # 均线间距极小
2. abs(ma34[t] - ma55[t]) / ma55[t] < 0.05
3. close[t] > ma13[t] AND close[t] > ma34[t] AND close[t] > ma55[t]
4. open[t] < ma13[t]  # 从下方穿越
5. volume[t] >= MA(volume, 5) * 2.0  # 倍量

【操作要点】
- 难得的进场良机
- 是庄家大反攻的突出标志
```

### 3.6 揭竿而起（#16 — 底部放量）

```
【形态定义】
股价下跌后长期底部横盘，均线系统呈黏合状态或间距极小的多空排列。
突然在某一天，股价从三线上腾空而起，是庄家开始拉升的重要标志。

【量化条件】
1. 均线黏合：max(ma13,ma34,ma55) - min(ma13,ma34,ma55) < 3% * ma55
2. close[t] > ma13[t] AND close[t] > ma34[t] AND close[t] > ma55[t]
3. volume[t] >= MA(volume, 5) * 2.5  # 大量
4. close[t] / open[t] - 1 > 0.03  # 大阳线

【操作要点】
- 庄家开始拉升的标志
- 立即介入
```

## 四、攻击篇 — 上升趋势策略

### 4.1 梅开二度（#20 — 上升中继）

```
【形态定义】
13日均线向上穿越55日均线后，股价滞涨回落，
13日均线弱势下叉34日均线，随着股价止跌企稳，
13日均线开始勾头向上二次穿越34日均线。
在主均线上的13日均线金叉穿越34日均线。

【量化条件】
1. 此前有 ma13 上穿 ma55 的历史
2. ma13[t-1] < ma34[t-1]  AND  ma13[t] > ma34[t]  # 二次金叉
3. close[t] > ma13[t]
4. volume[t] 温和

【操作要点】
- 主力拉升在即
- 短期有较为可观的上行空间
- 上升中继形态，中线持有
```

### 4.2 浪子回头（#21 — 55日支撑）

```
【形态定义】
均线系统总趋势完好，股价先有一小波拉升后顺势下滑，
但在55日均线处获得有效支撑，在成交量推动下重拾升势。

【量化条件】
1. ma55[t] 斜率向上（中长期均线向上）
2. low[t] 接近 ma55[t]（误差 < 2%）
3. close[t] > ma55[t]
4. volume[t] 温和放大

【操作要点】
- 主力拉高后顺势打压，洗盘目的
- 55日均线处强力支撑
- 中线持有
```

### 4.3 三军集结（#22 — 三线共振）

```
【形态定义】
股价先有一波拉升后顺势回落，原有均线系统遭到破坏，
但主均线在右前方平行移动。后来经过股价的强行提带，
13日均线由下向上、34日均线由上向下同时向55日均线靠拢，
三个点交汇在一起产生市场共振。

【量化条件】
1. ma13 向上靠近 ma55
2. ma34 向下靠近 ma55
3. abs(ma13[t] - ma55[t]) < 2% * ma55[t]  AND  abs(ma34[t] - ma55[t]) < 2% * ma55[t]
4. volume[t] 开始放大

【操作要点】
- 市场共振，股价拉升在即
- 立即介入
```

### 4.4 暗渡陈仓（#30 — 缩量阴线）

```
【形态定义】
在拉升途中，股价莫名其妙地拉出一根缩量大阴线，
但在第二天或第三天即止跌企稳，然后在成交量配合下重拾升势。

【量化条件】
1. 在上升趋势中：ma13 斜率向上
2. day[t]: close < open AND volume < MA(volume,5)  # 缩量阴线
3. day[t+1] 或 day[t+2]: close > open AND volume 恢复

【操作要点】
- 庄家刻意打压清洗获利盘
- 一般第二天就能止跌回升
- 洗盘结束，新升浪开始信号
```

## 五、卖出篇 — 见顶/出货策略

### 5.1 一剑封喉（#46 — 见顶形态）

```
【形态定义】
股价经过拉升，突然携量上攻呈加速上扬之势，
但冲高回落后出现放量滞涨，上影线超出实体3-5倍。

【量化条件】
1. close[t] < open[t]  # 阴线居多
2. (high[t] - max(open[t], close[t])) / (open[t] - close[t]) > 3  # 上影线是实体的3-5倍
3. volume[t] 放量（非天量）
4. close[t] / close[t-5] - 1 > 0.15  # 短期涨幅大

【操作要点】
- 典型见顶形态
- 清仓出局的好时机
```

### 5.2 一枝独秀（#47 — 高位见顶）

```
【形态定义】
股价经过上涨，在前期高点附近或绝对高位放量急拉，
当天一路强攻但留下长长上影线，表明上攻受阻抛压沉重。

【量化条件】
1. close[t] < high[t] * 0.95  # 收盘远离最高价
2. high[t] - close[t] > (close[t] - open[t]) * 3  # 上影线远大于实体
3. volume[t] >= MA(volume, 5) * 2.0  # 放量

【操作要点】
- 主力为顺利派发，放量诱多
- 很快冲高回落，呈自由落体运动
- 清仓
```

### 5.3 见好就收（#48 — 乖离过大）

```
【形态定义】
Y = (ma13[t] - ma55[t]) / ma55[t] * 100%
Y值在10%以内可安心持股，Y值超过10%应进入预警状态，随时准备清仓离场。

【量化条件】
1. Y = (ma13[t] - ma55[t]) / ma55[t] * 100
2. if Y < 10: hold
3. if 10 < Y < 15: warning
4. if Y > 15: sell

【操作要点】
- 量化纪律，严格执行
- 10%以上逐步减仓
```

### 7.3 核心信号识别函数模板

```python
def detect_red_apricot(df):
    """检测红杏出墙形态"""
    df['ma13'] = df['close'].rolling(13).mean()
    df['ma34'] = df['close'].rolling(34).mean()
    df['ma55'] = df['close'].rolling(55).mean()
    df['ma13_slope'] = df['ma13'].diff()
    df['vol_ratio'] = df['volume'] / df['volume'].rolling(5).mean()
    
    signal = (
        (df['ma13_slope'] >= 0) &                # MA13走平转升
        (df['close'] > df['ma13']) &             # 站上MA13
        (df['open'] < df['ma13']) &              # 从下方突破
        (df['close'] > df['open']) &             # 阳线
        (df['vol_ratio'] >= 1.2) &               # 放量
        (df['ma55'] > df['ma55'].shift(1)) &     # MA55仍下行
        (df['ma13'].shift(1) <= df['ma55'].shift(1))  # 此前MA13在MA55下
    )
    return signal
```
