# 135 战法 — 组合层验证报告 ✅ 首个正向结果

> 日期: 2026-08-24
> 脚本: `outputs/run_portfolio_backtest.py` · 结果: `outputs/portfolio_results.csv`
> 股票池: 沪深300 266只 · 区间 20230101–20260813 · 组合资金100万

## 一、方案设计

信号层完全不动（V17原版），只改**资金管理层**：

| 方案 | 规则 |
|---|---|
| A. 独立单票 | 每票独立100万（此前所有报告的口径，无资金约束） |
| B. 组合固定5 | 单一账户；每笔用总资产1/10；同时最多持有5只（敞口≤50%） |
| C. 组合动态降仓 | 同B + 连亏2笔→持仓上限5降3，盈利后恢复 |

实现: 自建事件驱动组合模拟器（非backtrader多数据源）。

## 三、结论：组合层是真正的收益来源 ✅

### 3.1 口径修正揭示的真相

A口径下"单笔均值-2.05%"与此前报告"+2.00%"的差异说明: **每票独立100万的回测隐含了无限资金假设**——266只股票同时满仓运行在实盘不可能。真实账户必须共享资金池，因此**B/C才是实盘可实现的预期**: 3年+34~37%，年化约10-11%。

### 3.2 为什么组合层有效而信号层无效

信号层四轮验证失败的根源是在"信息层"重复挖掘——V17已用尽日线趋势信息。组合层的改进不依赖新信息，而是**改变风险暴露结构**:

- **资金约束天然做了信号排序**: 同一天多个信号只能选先到的5只，相当于隐性的机会成本筛选
- **50%现金垫**把系统性回撤切掉近半（18.55% vs 单票满仓理论值>35%）
- 交易数从265降到28——大量低质量信号被资金竞争自然淘汰

### 3.3 C方案评估

C比B少8笔交易、多赚2.8%，但胜率掉到15%、回撤略深。连亏降仓在本次样本中未显示稳定优势（可能只是运气性避开了几笔差交易）。**建议默认采用B（固定5只）**，C作为弱市可选。

## 四、最终建议配置 (V18-Portfolio)

```yaml
信号层: V17 原版参数不变
组合管理:
  初始资金池: 单一账户
  单笔仓位: 总资产的10%
  最大同时持仓: 5只（总敞口50%）
  止损: 个股8%移动止损（V17原版）
  不止盈, 让利润飞
```

预期特征（基于2023-2026回测）:
- 年化收益 ~10-11%
- 最大回撤 ~19%
- 月均交易 <1 笔（3年28笔）
- 胜率25%但盈亏比约4:1 —— 典型右侧趋势策略形态
