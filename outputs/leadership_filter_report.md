# 135 战法 — 方案E验证报告: 领先性龙头过滤 ❌ 未通过

> 日期: 2026-08-24
> 脚本: `outputs/run_leadership_filter.py` · 明细: `outputs/leadership_results.csv`
> 股票池: 沪深300 266只

## 一、方案设计

- 离线扫描全池每只股票的135买入信号时点
- 板块内**第一个**触发135信号的股票 = 本轮龙头信号；其后10个交易日内同板块其他股票的信号 = 跟随信号，允许买入
- 板块近10日无任何信号 → 孤立假信号，拦截（龙头本身也允许买）

## 二、结果 (266只)

| 指标 | A. V17基准 | E. 领先龙头 |
|---|---|---|
| 平均总收益 | +2.00% | -0.38% |
| 胜率 | 33.0% | 26.6% |
| 单笔平均收益 | +1.34% | **-2.53%** |
| 交易数/票 | 5.82 | 1.36 |
| 得分占优 | — | **35%** |

交易保留率仅26%，且保留下来的交易单笔收益为负——**过滤不是"没起作用"，是起了反作用**。

## 三、失败原因分析

1. **样本覆盖断裂**: 沪深300成分股分散在90个一级行业，多数细分行业在池内只有0-2只成分股。"板块内先发信号"几乎无法形成联动证据——过滤实际变成了随机砍掉74%的交易。
2. **逻辑自反**: 135信号本身已是右侧趋势确认信号。要求"板块内有人先发"等于要求双重右侧确认，入场点系统性滞后，买到的都是二段跟风位。

## 四、总体结论（任务7/8/板块系列）

三轮独立验证一致表明：**V17的信号体系已接近其信息上限，任何额外的趋势类/动量类/联动类过滤层在全池口径下都无法提供净改善。**

| 尝试 | 占优比例 | 结论 |
|---|---|---|
| 参数收紧(任务7b) | 45% | 过拟合 |
| DMI趋势过滤(任务8) | 39% (生效子集65%) | 边际价值≈0，留作弱市模块 |
| 强板块动量 | 41% | 时段错配 |
| 领先龙头(E) | 35% | 样本断裂+双重确认滞后 |

**剩余可挖掘方向只有组合层面**（多票并行仓位分配、资金管理、信号去重）与执行层（滑点、分批）。建议停止单票信号层的过滤研究。
