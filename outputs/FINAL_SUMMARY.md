## 一、最终系统配置

### 1.1 信号层 — V17（参数冻结，不再改动）

**买入信号（三选一，需全部通过前置过滤）**

前置过滤:
1. 非下降趋势（MA13<MA34<MA55 且三线齐跌时禁止买入）
2. 收盘价 > MA55
3. MA55 五日内跌幅 ≤5%

| 信号 | 条件 |
|---|---|
| 红杏出墙 | MA13连续2日向上 + 收盘站上MA13 + 多头排列 + 放量(>5日均量) |
| 一阳穿三线 | 单日阳线开盘低于/收盘高于MA13/34/55 + 量能>2倍 |
| 揭竿而起 | 三线黏合≤1.5%(5日均值≤2%) + 放量2倍 + 阳线收于三线之上 |

**卖出规则**
- 一箭穿心: 放量1.5倍阴线跌破MA13且MA13拐头向下 → 全清
- 移动止损: 高点回撤8% → 全清
- 不设止盈——让利润飞
- 冷却期: 卖出后10个交易日

### 1.2 组合层 — Portfolio v1（本次研究核心成果）

```
账户:     单一资金池
单笔仓位: 总资产的10%
持仓上限: 同时最多5只（总敞口≤50%，一半现金）
优先级:   先到先得，资金不足则放弃该信号
```

### 1.3 实盘预期特征

| 指标 | 数值 |
|---|---|
| 年化收益 | ~10–11% |
| 最大回撤 | ~19% |
| 月均交易 | <1 笔（3年28笔） |
| 胜率 | ~25%（盈亏比≈4:1） |
| 收益/回撤比 | 1.84 |

策略形态: 典型右侧趋势跟踪——低胜率、高盈亏比、靠少数大赢家覆盖多数小亏损。

| # | 实验 | 全池占优 | 结论 | 报告 |

### 核心教训

1. **信号层已到信息上限**: V17的「均线多头+放量形态+MA55过滤」已提取A股日线级别几乎全部趋势信息。四轮独立的额外过滤（参数收紧/DMI/板块动量/领先龙头）全部在40%占优线附近失败——不是运气，是系统性证据。
2. **过拟合防线上**: 任何改动必须全池≥60%占优才可落地。任务7b若跳过验证直接上线V18参数，实盘将跑不出回测效果。
3. **收益在结构里不在信息里**: 组合层的改进不依赖任何新指标，仅通过资金约束（10%仓位×5只上限）就实现了信号的自然筛选和回撤减半。**风控即alpha。**

## 三、与BOSS交易哲学的对照

| BOSS原则 | 落地情况 |
|---|---|
| 只做多 | ✅ 系统无做空机制 |
| 生存第一 | ✅ 50%现金垫 + 个股8%移动止损 + 组合回撤19% |
| 右侧交易 | ✅ 三大买入信号全部为趋势启动确认形态 |
| 没机会就空仓 | ✅ 月均<1笔, 3年仅28笔; 现金垫常年在50%以上 |
| 让利润飞不止盈 | ✅ 无止盈设计, 仅移动止损退出 |
| 发现错误灵活止损 | ✅ 一箭穿心(信号错误)+移动止损(利润回撤)双通道 |
| 止损与洗盘的平衡点 | ⚠️ 8%为2023-2026单一时段最优, 未找到更优值(6-10%不敏感); 实盘可观察后再微调 |
| 结构性市场选牛板块龙头 | ❌ 两轮验证否决: 追强板块时段错配, 滞后动量龙头=追高。修正: V17的MA55过滤已隐含"只在强势股操作", 无需外挂板块判断 |
