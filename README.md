# 135策略量化交易系统

基于"135战法"的 A 股量化交易策略 - 独立回测验证系统

## 项目定位

135 战法是一套独立的技术交易策略系统，与"龙头战法选股系统"为两套完全不同的策略体系：
- **135 战法**: 基于经典技术形态（马失前蹄、见好就收、一阴破三线等）的量化回测验证
- **龙头战法**: 基于市场情绪和龙头股识别的趋势跟踪策略

## 功能特性

- **135战法信号识别**: 自动识别35种经典技术形态
- **多因子融合**: DMI趋势指标 + MACD动能指标
- **批量回测**: 支持全市场3000+股票批量回测
- **绩效分析**: 胜率、夏普比率、最大回撤等关键指标
- **实盘参数**: 止损/止盈策略可配置

## 快速开始

### 安装依赖

```bash
pip install backtrader baostock pandas numpy matplotlib
```

### 单股回测

```bash
python outputs/run_real_backtest.py --code sh.600000 --start 2023-01-01 --end 2026-08-13 --capital 100000
```

### 批量回测

```bash
# 前50只股票
python outputs/run_real_backtest.py --top 50 --start 2023-01-01 --end 2026-08-13 --capital 100000

# 全市场回测
python outputs/run_real_backtest.py --start 2023-01-01 --end 2026-08-13 --capital 100000
```

### 保存结果

```bash
python outputs/run_real_backtest.py --top 50 --start 2023-01-01 --end 2026-08-13 --output outputs/result.csv
```

## 策略说明

### 核心信号

| 信号名称 | 描述 | 类型 |
|---------|------|------|
| 见好就收 | 趋势延续确认 | 买入 |
| 马失前蹄 | 回调确认 | 买入 |
| 一阴破三线 | 趋势反转 | 卖出 |
| 落井下石 | 强势回调 | 买入 |
| 过河拆桥 | 支撑破位 | 卖出 |
| 独上高楼 | 突破确认 | 买入 |
| 一箭穿心 | 均线支撑 | 买入 |
| 黑客点击 | 启动信号 | 买入 |

### 技术指标

- **DMI (方向运动指数)**: 判断趋势强度
- **MACD (指数平滑异同移动平均线)**: 判断动能变化
- **均线系统**: 5/10/20/60日均线交叉确认

## 回测配置

```bash
--start 2023-01-01          # 开始日期
--end 2026-08-13            # 结束日期  
--capital 100000            # 初始资金
--stop-loss 0.07            # 止损比例 (7%)
--take-profit 0.20          # 止盈比例 (20%)
--top 50                    # 回测前N只股票
--code sh.600000            # 指定股票
```
