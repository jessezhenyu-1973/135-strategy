# 135策略量化交易系统

基于"135战法"的 A 股右侧趋势交易系统 — V17 信号层 + 组合资金管理（已全池验证）

> **当前状态**: 研究阶段完成。信号层参数冻结，组合层验证通过。
> 📄 **最新总结**: [outputs/FINAL_SUMMARY.md](outputs/FINAL_SUMMARY.md)

## 项目定位

135 战法是一套基于13/34/55日均线组合（斐波那契数列）的经典技术交易系统。本项目将其提炼为**三个核心买入信号 + 一个核心卖出信号**的右侧趋势策略，并通过四轮严格的样本外验证确立了最终配置。

**设计哲学**（与回测数据互相印证）:
- 只做多、生存优先——50%现金垫 + 8%移动止损
- 右侧交易——只在趋势启动确认后入场
- 没有交易机会就空仓——月均不到1笔
- 让利润飞——不止盈，仅移动止损退出

## 最终配置（V17 + Portfolio v1）

### 信号层

| 类别 | 规则 |
|---|---|
| 前置过滤 | 非下降趋势；收盘>MA55；MA55五日跌幅≤5% |
| 买入① | **红杏出墙**: MA13连续2日向上+站上MA13+多头排列+放量 |
| 买入② | **一阳穿三线**: 单日阳线穿越三线+量能2倍 |
| 买入③ | **揭竿而起**: 三线黏合≤1.5%+放量2倍+突破 |
| 卖出① | **一箭穿心**: 放量1.5x阴线跌破拐头向下的MA13 → 全清 |
| 卖出② | **移动止损**: 高点回撤8% → 全清 |
| 其他 | 不止盈 · 冷却期10个交易日 |

### 组合层（实盘关键）

```
单笔仓位:   总资产10%
持仓上限:   同时最多5只（总敞口≤50%）
资金池:     单一账户，先到先得
```

## 研究结论（为什么是这套配置）

2026-08 完成了对信号层的系统性挖掘，**四轮独立验证全部否决了额外过滤**：

| 实验 | 全池占优比例 | 结论 |
|---|---|---|
| 参数收紧调优 (324组网格) | 45% ❌ | 小样本过拟合 |
| DMI 趋势过滤 | 39% ❌ | 与V17自带趋势过滤信息重叠 |
| 强板块动量筛选 | 41% ❌ | 追强板块=买在趋势后半段, 时段错配 |
| 板块领先龙头 | 35% ❌ | 双重右侧确认→系统性滞后追高 |
| **组合层资金管理** | **✅** | **+34%/3年, 风控即alpha** |

**核心发现**：V17 的信号体系已用尽日线级别趋势信息；真正的收益提升来自组合层——10%仓位×5只上限的资金约束天然完成信号筛选，并把回撤砍半。详见 [outputs/FINAL_SUMMARY.md](outputs/FINAL_SUMMARY.md)。
